repository.

## Changing this file or a SKILL

`AGENTS.md` and files under `skills/` are agent-executed instructions, not documentation — an
agent acts on them directly, so an error here becomes an error in every PR an agent opens
afterward. Treat changes to this file or any `skills/**/SKILL.md` as code, not docs:

- Requires review from the reviewer group, enforced by `CODEOWNERS`.
- No unreviewed edits, including agent self-edits made mid-task — open a PR like any other change.

## Commits and PRs

See `CONTRIBUTING.md` for the general contribution, testing, and PR requirements — they apply to
every change, agent-authored or not. No AI-attribution footers, co-author trailers, or
"generated by" language in commits or PR bodies.
